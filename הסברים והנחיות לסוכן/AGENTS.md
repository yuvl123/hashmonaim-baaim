# החשמונאים באים — אתר משחק רביעיות אונליין

- **טכנולוגיה**: Next.js (App Router), TypeScript, Tailwind CSS, Vercel Blob (אחסון חדרים פרטי), Supabase Realtime Broadcast (סנכרון חי), `qrcode.react`.
- **תמונות הקלפים**: 48 קלפים + גב המנורה ב־`public/cards/`, נשלפו מה־PDF הסופי `תיקון אות ופסים`.
- **הרצה מקומית**: `npm.cmd run dev`
- **בדיקת build**: `npm.cmd run build`
